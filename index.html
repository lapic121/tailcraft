TailCraft

포트포워딩 없이, 설치 하나로 여는 마인크래프트 서버

EXE 하나를 실행하면 GUI 런처가 뜨고, 처음 켜면 8단계 튜토리얼이 버튼을 눌러가며 서버 완성까지 안내합니다. Java·서버 파일은 자동으로, 친구 초대는 안내문 복사 한 번으로.

공식 배포처에서 실행 시점에 내려받습니다. 필요한 Java(8·17·21·25)는 버전에 맞춰 자동 설치됩니다.

Paper

플러그인·바닐라 최적화. 대부분의 친구 서버에 적합. 바닐라 클라이언트로 접속 가능.

Fabric

가벼운 모드. Fabric API 자동 설치. 친구도 같은 모드 필요.

NeoForge · Forge

대형 모드팩. 인스톨러 자동 처리, 친구용 모드 zip 내보내기 지원.

Arclight

Forge·NeoForge·Fabric 서버에서 Bukkit 플러그인(EssentialsX 등)까지 함께 사용하는 하이브리드.

버전 자동 로드

마인크래프트 버전·빌드를 공식 API에서 실시간으로 받아 드롭다운에 채웁니다.

jar 미동봉

서버 파일을 재배포하지 않고 공식 서버에서 직접 다운로드 — 라이선스 안전.

실시간 대시보드

CPU·RAM·디스크·접속자를 실시간으로. 램 할당은 슬라이더로 즉시 변경, 친구용 안내문은 복사 한 번.

모드·플러그인 관리

Modrinth 검색·설치(필수 의존성 자동), 사용/사용 안 함 토글, 추천 세트, 친구용 모드 zip 내보내기.

디버깅 도구

콘솔 빠른 명령 버튼과 즐겨찾기, 진단 실행(Java·포트·방화벽·테일스케일·로그를 한 번에 수집·복사).

How it works

다운로드부터 친구 접속까지

받고 실행

zip을 풀고 TailCraft.exe 실행. 라이선스 동의 후 8단계 튜토리얼이 시작됩니다.

서버 선택·설치

서버 종류·버전을 고르고 설치. Java와 서버 파일, 기본 플러그인까지 자동.

초대·접속

방화벽 버튼 → 친구용 안내문 복사 → 친구에게 전송. 끝.

SmartScreen 경고가 뜨면

서명되지 않은 개인 배포라 "Windows의 PC 보호" 창이 나올 수 있습니다. 추가 정보 → 실행을 누르면 됩니다. 한 번 실행하면 다시 뜨지 않습니다.

알아두기

서버 jar·Java·플러그인은 동봉하지 않고 최초 실행 시 각 공식 배포처에서 받습니다. 서버 실행에는 Minecraft EULA 동의가 필요합니다. Tailscale 무료 플랜은 개인 용도 전용입니다.

소스 공개 · 무결성 검증

코드는 GitHub에서 누구나 열람할 수 있습니다(소스 공개형). 받은 파일이 공식본인지 certutil -hashfile TailCraft.exe SHA256 로 확인하세요 — 값은 저장소 README에 있습니다.
